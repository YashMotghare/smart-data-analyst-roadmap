// Interview Preparation

Top Interview Q&A Bank

35+ real interview questions across SQL, Python, Stats, Excel, Viz & HR. Click to reveal model answers.

What is the difference between WHERE and HAVING?SQL▾
WHERE filters rows before grouping; HAVING filters groups after GROUP BY. You can use WHERE on individual row columns, but for aggregate conditions (like SUM > 1000), you must use HAVING.SELECT dept, SUM(salary) as total FROM employees WHERE status = 'active' GROUP BY dept HAVING SUM(salary) > 500000;
Explain the different types of JOINs with examples.SQL▾
INNER JOIN: returns rows where match exists in both tables. LEFT JOIN: all rows from left + matching rows from right (NULLs for no match). RIGHT JOIN: opposite of LEFT. FULL OUTER JOIN: all rows from both, NULLs where no match.-- Get all customers even if they have no orders SELECT c.name, o.order_id FROM customers c LEFT JOIN orders o ON c.id = o.customer_id;
What are Window Functions? Give an example.SQL▾
Window functions perform calculations across rows related to the current row without collapsing them. Unlike GROUP BY, each row retains its identity. Common functions: RANK(), ROW_NUMBER(), LAG(), LEAD(), SUM() OVER().SELECT name, salary, RANK() OVER (PARTITION BY dept ORDER BY salary DESC) as rank_in_dept FROM employees;
How do you find duplicate records in a table?SQL▾
Use GROUP BY on the columns you're checking for duplicates, then filter with HAVING COUNT(*) > 1.SELECT email, COUNT(*) as cnt FROM users GROUP BY email HAVING COUNT(*) > 1;
Write a query to find the second highest salary.SQL▾
Two approaches: subquery or LIMIT+OFFSET.-- Method 1: Subquery SELECT MAX(salary) FROM employees WHERE salary < (SELECT MAX(salary) FROM employees); -- Method 2: LIMIT SELECT DISTINCT salary FROM employees ORDER BY salary DESC LIMIT 1 OFFSET 1;
How do you handle missing values in Pandas?Python▾
First detect with df.isnull().sum(). Then decide strategy: drop rows/columns with dropna(), fill with a constant or statistical value using fillna(), or use interpolation for time-series data.df.isnull().sum() # detect df.dropna(inplace=True) # drop rows df['col'].fillna(df['col'].mean(), inplace=True) # fill mean df['col'].fillna(method='ffill', inplace=True) # forward fill
What is the difference between loc and iloc in Pandas?Python▾
loc uses label-based indexing (row labels, column names). iloc uses integer position-based indexing (0, 1, 2... positions). loc is inclusive on both ends; iloc is exclusive on the end like Python slicing.df.loc[0:5, 'salary'] # rows 0-5 by label, column by name df.iloc[0:5, 2] # rows 0-4 by position, 3rd column
How do you perform groupby and aggregation in Pandas?Python▾
groupby() splits data into groups, then you apply an aggregation function. You can apply multiple aggregations using .agg().df.groupby('department')['salary'].mean() df.groupby('dept').agg({ 'salary': ['mean', 'max'], 'employees': 'count' })
What is the difference between mean, median, and mode? When to use each?Statistics▾
Mean: arithmetic average — sensitive to outliers. Use for normally distributed data. Median: middle value when sorted — robust to outliers. Use for skewed data like income or house prices. Mode: most frequent value — useful for categorical data.

Example: Salary data with one CEO earning ₹1Cr — median gives better "typical" salary than mean which gets pulled up by the outlier.
Explain correlation vs causation with an example.Statistics▾
Correlation means two variables move together. Causation means one directly causes the other. Correlation ≠ causation. Classic example: Ice cream sales and drowning deaths are correlated (both peak in summer) — but ice cream doesn't cause drowning. The hidden cause is summer/heat. In data analysis, always think about confounding variables before claiming causation.
What is a p-value? How do you interpret it?Statistics▾
A p-value is the probability of observing your data (or more extreme) if the null hypothesis is true. Typically we use α = 0.05 as threshold. p < 0.05: reject null hypothesis, result is statistically significant. p > 0.05: fail to reject null hypothesis. Important: p-value does NOT measure effect size or practical significance — a tiny useless difference can be statistically significant with a huge sample.
What is the difference between VLOOKUP and INDEX-MATCH?Excel▾
VLOOKUP looks in the first column only and returns data to the right — breaks if you insert columns. INDEX-MATCH is more flexible: INDEX returns value at a position, MATCH finds the position. INDEX-MATCH can look left, is faster on large data, and doesn't break when columns are inserted.=VLOOKUP(A2, B:D, 2, 0) -- looks up A2 in column B =INDEX(C:C, MATCH(A2, B:B, 0)) -- equivalent, more robust
How do you remove duplicates and clean data in Excel?Excel▾
Remove duplicates: Data tab → Remove Duplicates → select columns. Clean text: TRIM() removes extra spaces, PROPER() fixes capitalization, CLEAN() removes non-printable characters. For standardization: use Find & Replace, Flash Fill, or Power Query for bulk transformations. Power Query is the professional approach for repeatable cleaning.
When would you use a bar chart vs a line chart?Visualization▾
Bar chart: for comparing discrete categories (e.g. sales by product, revenue by region). Good when order doesn't matter. Line chart: for showing trends over continuous time (e.g. monthly revenue, stock price over years). The connected line implies continuity. Never use a line chart for unrelated categories — it implies a relationship that doesn't exist.
How do you make dashboards that non-technical stakeholders can understand?Visualization▾
1) Lead with KPIs at the top (headline numbers). 2) Use clear, plain-English titles that state the insight, not just the chart name. 3) Limit to 5–6 charts max per dashboard. 4) Use consistent colors — one color for one category throughout. 5) Add context: targets, previous period comparisons. 6) Avoid 3D charts, pie charts with 5+ slices. 7) Always answer "So what?" — what action should this drive?
Tell me about yourself (for a fresher DA role).HR▾
Use the Present-Past-Future formula: "I'm a final-year Electrical Engineering student from Nagpur with strong data skills. I've completed training with Hitachi India on IIoT energy monitoring systems, giving me hands-on experience with real industrial data. I built AI-powered web applications using APIs and have advanced Excel skills including pivot tables and Power Query. I'm passionate about turning data into decisions, and I'm looking for a Data/Business Analytics internship where I can apply these skills to real business problems."
Why do you want to move from Electrical Engineering to Data Analytics?HR▾
Frame it as a natural evolution, not a pivot: "My IIoT project at Hitachi showed me that the real value isn't just in building systems — it's in analyzing the data they generate to drive efficiency decisions. I worked with energy monitoring data and realized I wanted to go deeper into analytics. My engineering background actually gives me an advantage — I understand the domain context behind industrial data that a pure CS/IT candidate wouldn't have."
Describe a time you solved a problem using data.HR▾
Use STAR method (Situation, Task, Action, Result). Example: "During my IIoT project at Hitachi (Situation), we needed to understand energy consumption patterns (Task). I collected RS-485 Modbus data, analyzed it in Excel with pivot tables and Power Query (Action), and identified that peak consumption occurred during shift transitions — a 15% efficiency opportunity (Result)." — Tailor to your actual experiences with real numbers when possible.
Where do you see yourself in 3 years?HR▾
Be honest but ambitious: "In 3 years, I see myself as a skilled Data Analyst who has worked across multiple business domains — ideally growing toward a Senior Analyst or Business Intelligence role. I want to have mastered SQL, Python, and BI tools in a real production environment, and I'm interested in eventually combining my engineering domain knowledge with advanced analytics like ML-based forecasting."
// Job Hunt Strategy

How to Apply & Get Hired

A systematic approach to finding, applying, and following up on Data Analyst roles.

📝 Resume Tips
  • Lead with a 2-line Summary: "Data Analyst skilled in SQL, Python, Excel & Power BI with experience in IIoT energy data"
  • Quantify everything: "Analyzed 50K+ rows of sensor data" not "worked with data"
  • Match keywords from the Job Description (ATS systems scan for them)
  • Skills section: SQL, Python, Excel, Power BI, Tableau, Statistics — list what you know
  • Projects section is more important than education for freshers
  • Keep to 1 page. Use Jake's Resume template (LaTeX) or Canva's ATS-friendly template
  • Add GitHub profile URL and LinkedIn URL in the header
💼 LinkedIn Optimization
  • Headline: "Aspiring Data Analyst | SQL • Python • Power BI | B.E. Electrical Engineering"
  • Add "Open to Work" — set it to Data Analyst, Business Analyst, Analytics Intern
  • Feature your best project or GitHub in the Featured section
  • Add all certifications: Excel, Hitachi IIoT training, any Kaggle/Coursera certificates
  • Post about your projects — 1 post per week builds visibility
  • Connect with 50+ Data Analysts in India — engage with their posts
  • Message recruiters directly with a short personalized note (1–2 lines)
📧 Cold Outreach Template
  • Subject: "Data Analyst Intern — [Your Name], B.E. EE, Nagpur"
  • Line 1: One genuine compliment about their company or work
  • Line 2: Who you are + 1–2 relevant skills/projects (very brief)
  • Line 3: Clear ask — "I'd love to contribute as a data analytics intern for June"
  • Attach your resume + GitHub link
  • Follow up in 5–7 days if no reply
  • Target HR + the Analytics team lead — message both on LinkedIn
✅ Application Checklist
  • Resume tailored to each JD (swap skill order to match their keywords)
  • Cover letter: 3 paragraphs — why them, what you bring, call to action
  • GitHub has at least 3 pinned projects with good READMEs
  • LinkedIn profile 100% complete with profile photo
  • Apply to 10–15 jobs per day during active search
  • Track all applications in a spreadsheet (company, date, status, follow-up)
  • Prepare 3 project stories using STAR method
